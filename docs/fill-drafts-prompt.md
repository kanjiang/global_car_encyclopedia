# 用网页版 AI 补全车型草稿

自动流水线只能从维基百科拿到品牌、产地、年份、功率和配图，**极速、零百加速、参考价、座位数、中文文案**要人来补。
这份文件是给网页版 AI（豆包、Kimi、ChatGPT 等均可）用的提示词，不需要 API key，也不需要装任何东西。

## 三步走

1. 打开 `data/incoming.json`，全选复制。
2. 把下面「提示词正文」整段粘进 AI 对话框，再把 JSON 粘在后面，发送。
3. 把 AI 返回的 JSON 覆盖回 `data/incoming.json`，然后在项目目录执行：

```bash
npm run cars:merge   # 校验并写入 js/data.js，缺字段会被拦下
npm test             # 依赖检查 + 数据校验 + 页面冒烟测试
```

两条命令都通过，就可以提交了。要是 `cars:merge` 报错，照着报错信息改 `incoming.json` 再跑一次即可，坏数据进不了线上。

## 提示词正文

复制下面代码块里的全部内容：

```text
你在帮我维护一个给小朋友看的中文汽车科普网站。我会给你一段 JSON，里面是几款新车的草稿，
有些字段是 null 或空字符串，需要你补齐。请严格按下面的规则输出。

【最重要的一条】
参数必须是真实查到的官方数据，不确定就把该字段留成 null，并在 JSON 之外单独告诉我哪几项没把握。
绝对不要编数字、不要用"大概""估计"凑一个值。同一款车如果有多个版本，统一按你选定的那个版本填，
并在 JSON 之外说明你用的是哪个版本。

【要补的字段】
- priceRMB：字符串，形如 "约 30 万元"。进口车可写 "约 52 万元"，按官方起售价换算成人民币，取整到万位。
- power：字符串，必须形如 "469 马力"（网站按这个格式解析数值来排序）。公制马力 PS 和 hp 差别不大，按官方公布的马力数写。
- topSpeed：数字，单位 km/h，范围 30–500。电子限速的车按限速值写。
- accel：数字，0–100 km/h 加速秒数，范围 0.1–120。
- seats：整数，座位数。
- summary：一句话，不超过 20 个汉字，点出这款车最鲜明的特点。例："猎装造型的高性能纯电旅行车。"
- description：2–3 句话，100–200 字，讲清楚它是什么车、有什么本事，用小学生能懂的说法。
  可以打比方（"比很多超级跑车还快"），但比喻背后的数字要真实。
- facts：2–3 条冷知识，每条一句话，是那种小朋友会觉得"哇"的细节，
  比如生产地、名字来历、某项世界纪录、车里的有趣配置。不要和 description 重复。

【要核对的字段】
- name：只写车型名，不带品牌。例如品牌是 "BMW 宝马" 时，name 写 "i3 50 xDrive" 而不是 "BMW i3"。
- category：只能从这几个里选一个：超级跑车、跑车、豪华轿车、SUV、电动车、越野、经典老爷车、家用轿车、皮卡、卡车、工程车、巴士、赛车。
  插电混动车不算"电动车"，按车身形态选（比如插混 SUV 就写 SUV）。
- country：只能从这几个里选一个：法国、意大利、德国、日本、英国、美国、中国、瑞典、韩国、奥地利。
  按品牌的母国填，不按产地填（起亚在斯洛伐克生产也写"韩国"）。如果都不匹配，保持原值并告诉我。
- engine：简短的中文描述，如 "纯电驱动"、"双电机纯电"、"2.0T 插电混动"、"6.5L V12"。
  如果原值里有 "{{" 这类维基模板残留，请改写成正常中文。
- drivetrain：只写 "前驱"、"后驱" 或 "四驱"。
- year：上市/量产年份。

【不要动的字段】
id、accent、emoji、_source、_imageBytes 保持原样。补完后把每条的 "_todo" 改成空数组 []。

【文风】
全部用简体中文，语气亲切、平实，像在给孩子讲解，不要营销腔（禁用"重塑""标杆""诠释"这类词）。
数字和单位之间留一个空格，例如 "469 马力"、"317 公里"。

【输出格式】
先输出补全后的完整 JSON（和输入结构一致，能直接保存成文件），
再在 JSON 后面用几句话说明：每款车你参考的版本、以及哪些数据你没把握。
```

## 粘回去之前，自己扫一眼

AI 最容易出问题的地方，按踩坑频率排：

- **数字是编的**。挑一两个参数去官网或汽车之家搜一下，对不上就别用。
- **繁体字混进来**。搜一下"車""電""動"这几个字，有就说明串了繁体语料。
- **`power` 格式跑偏**，写成 "469马力"（少空格）或 "345 kW"。`npm test` 会拦，但自己先改更快。
- **类别或产地写了白名单外的值**，比如"轿车""斯洛伐克"。
- **`facts` 和 `description` 讲同一件事**，读起来像重复。

如果哪款车实在查不到可靠数据，最省事的做法是把那一整条从 `incoming.json` 里删掉，
再去 `tools/seen.json` 里把它的维基标题对应的值写成 `"-"`，以后就不会再被提名了。
